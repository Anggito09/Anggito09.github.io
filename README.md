# KameraIn

Website resmi KameraIn untuk melihat katalog, harga sewa, paket film, galeri, dan melakukan booking kamera Instax melalui WhatsApp.

## Menjalankan secara lokal

```bash
npm install
npm run dev
```

## Membuat versi produksi

```bash
npm run build
```
